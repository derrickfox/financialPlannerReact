# Rent vs Buy Calculator

Interactive React calculator for comparing the long-term cost of renting an apartment versus buying a home.

Also includes a second, style-matched Retirement Calculator page with persistent inputs when switching between calculators.

## What it models

- Rent growth and renter insurance
- Mortgage payment (principal + interest)
- Property tax, maintenance, home insurance, HOA
- Closing and selling costs
- Home appreciation
- Investment growth for the renter scenario
- Inflation on recurring non-mortgage costs

The charts and summary update immediately as inputs change.

Retirement calculator highlights:
- Category-based monthly expense planner (today dollars)
- Inflation-adjusted monthly budget at retirement
- Estimated sustainable monthly spending at retirement
- Monthly cushion/shortfall view for budgeting

## Run locally

```bash
npm install
npm run dev
```
